# MedExplain

MedExplain is an AI-powered medical report explanation platform that helps users understand medical reports in simple, accessible language.

## Project Status

🚧 Currently under development.

## Planned Features

- Medical report PDF upload
- PDF text extraction
- OCR for scanned reports
- Evidence-grounded explanations using RAG
- Medical terminology explanations
- Reference-range interpretation
- Authoritative medical knowledge retrieval
- Follow-up questions about uploaded reports
- Safety-focused response generation
